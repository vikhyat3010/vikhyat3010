An intelligent fleet monitoring platform designed to help transport operators monitor vehicles, detect operational anomalies, and make faster decisions.

**Key Features**

- 📍 Real-time / simulated fleet tracking
- 🗺️ Interactive route & vehicle dashboard
- ⚠️ Anomaly and delay detection
- 📊 Fleet & route analytics
- 🤖 ML-assisted delay prediction
- 🔔 Intelligent alerts & recommendations
- 🌐 Full-stack web dashboard

> **Goal:** Make fleet operations more intelligent, visual, and data-driven.
